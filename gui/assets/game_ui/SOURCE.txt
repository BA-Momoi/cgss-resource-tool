These bundles use an NGUI UIAtlas. The slice names and rectangles are stored in
MonoBehaviour/UIAtlas.json as mSprites; they are not Unity Sprite assets, so
AssetStudio exports no Sprite directory. The PNG files here are untouched full
Texture2D exports.
